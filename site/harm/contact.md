# Contact and feedback

Questions, problems and ideas about HaRM all go to the same place, and every message is read.

## Send feedback from HaRM

**Settings > About > Send feedback** starts an email to ZomBeatz Media with your HaRM version and device already filled in. Write what happened or what you'd like, and send it.

Or email **[info@zombeatzmedia.com](mailto:info@zombeatzmedia.com)** directly.

## Reporting a bug

A good report gets a fix faster. Include:

1. **What you did**, step by step ("Opened a device, pressed ⋯ > Import specs…, chose Over SSH").
2. **What happened**, and what you expected instead. Copy any error message word for word.
3. **Your HaRM version** (Settings > About) and where it runs: Windows, Linux, Docker, or a phone (which one).
4. **A screenshot**, if it shows the problem. Check it doesn't show passwords or addresses you'd rather keep private.
5. If HaRM won't start: the **Server log** from the control panel (or `docker logs zoms-harm` on a server).

Never send your master password, recovery code or the `data` folder. Nobody at ZomBeatz Media will ever ask for them.

## On GitHub

HaRM is open source. On [GitHub](https://github.com/ZomBeatz/Zoms-HaRM) you can report a problem or suggest a feature under **Issues**, see what's being worked on, and read the code.

## Helping to test

Want to try new versions before they're released? Email [info@zombeatzmedia.com](mailto:info@zombeatzmedia.com) with what you run HaRM on (Windows, Linux, a server, which phone). The [live demo](https://zombeatz.github.io/Zoms-HaRM/) always runs the newest code, so it's also a quick way to see what's changed.
