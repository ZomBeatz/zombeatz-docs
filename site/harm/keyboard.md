# Keyboard shortcuts

The keys that make HaRM faster on a computer. They're the same in every ZomBeatz app, and HaRM lists them in **Help > Keyboard shortcuts** and **Settings > Shortcuts** (or press <kbd>?</kbd>).

Single keys like <kbd>N</kbd> and <kbd>/</kbd> never fire while you're typing in a box or have a dialog open. On a Mac, use <kbd>⌘</kbd> where this page says <kbd>Ctrl</kbd>.

## Getting around

| Keys | Does |
|---|---|
| <kbd>Ctrl</kbd> <kbd>K</kbd> | Search everything: devices, IPs, MACs, serials, parts, places, networks and logins |
| <kbd>/</kbd> | Filter the list on this page (devices, parts, logins…). On pages without a list, it searches everything. |
| <kbd>[</kbd> | Fold the sidebar to icons, or open it again. HaRM remembers it on this computer. |
| <kbd>?</kbd> | Help, open at this list of shortcuts |

## Adding and closing

| Keys | Does |
|---|---|
| <kbd>N</kbd> | Opens **+ New**: add a device, part, login, network, holder or place, or start from a label or AI Assist. <kbd>Tab</kbd> moves through it and <kbd>Enter</kbd> picks. |
| <kbd>Esc</kbd> | Closes the dialog, menu or search you're in. In the search box, it clears it too. |
| <kbd>Enter</kbd> | In a note box: adds the note. <kbd>Shift</kbd> <kbd>Enter</kbd> starts a new line instead. |

## Zoom

| Keys | Does |
|---|---|
| <kbd>Ctrl</kbd> <kbd>+</kbd> | Bigger |
| <kbd>Ctrl</kbd> <kbd>−</kbd> | Smaller |
| <kbd>Ctrl</kbd> <kbd>0</kbd> | Back to normal size |

Zoom is your browser's own, so HaRM remembers it per computer like any website.

## Tips

- Every table sorts by clicking its header; click again to reverse it.
- <kbd>Tab</kbd> and <kbd>Shift</kbd> <kbd>Tab</kbd> move between buttons and fields, with a visible ring on the one that has focus.
- On phones and tablets, the same things are in the top bar (**Search**, **+ New**) and the bottom bar.
