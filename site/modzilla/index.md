# Zom's Modzilla

**Zom's Modzilla** is a free mod manager for Linux and the Steam Deck. It downloads mods from Nexus Mods and Thunderstore, keeps them in a tidy library, and puts a profile's mods into a game when you press **Play**, then takes them out again. It checks for conflicts by itself and helps when a game won't start.

There's no account of its own and no tracking. Your Nexus Mods API key stays on your computer.

## What you can do

| | |
|---|---|
| **[Download mods](./downloads)** | One at a time, several at once, or matched to your account. Free accounts click each file on the website, as Nexus Mods asks; Premium gets them straight away. Downloads resume after a dropped connection, a restart or sleep. |
| **[Collections](./collections)** | Paste a collection's address, or use its button on the website: every file is queued, with a profile made from it. |
| **[Profiles and Play](./profiles-and-play)** | Sets of mods per game, in load order. **Play** puts them in and starts the game ([Profiles and Play](./profiles-and-play)). |
| **[A conflict check](./conflict-check)** | Which mods overwrite which files, missing requirements and plugin masters, mods packed a folder too deep, and loaders that need a launch option under Proton. |
| **[Game tools](./game-tools)** | Script extenders started from Steam, Visual C++ and .NET in the Proton prefix, xEdit and Nemesis run in the prefix, UE4SS and ReShade ([Game tools](./game-tools)). |
| **[Thunderstore too](./thunderstore)** | 340+ games' mods (Valheim, Lethal Company, R.E.P.O.…), r2modman and Mod Organizer 2 profiles brought across, tModLoader for Terraria. |
| **[Bethesda](./bethesda) and [Baldur's Gate 3](./baldurs-gate-3)** | LOOT plugin sorting, and BG3's .pak mods and mod list. |
| **[Saves](./saves)** | Saves per profile, and snapshots before trying risky mods. |
| **[Optional AI help](./ai-help)** | Any AI service, with the check and the logs gathered for it. You see everything before it's sent. |
