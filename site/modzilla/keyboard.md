# Keyboard and controller

## Keyboard

| Keys | Does |
|---|---|
| `Ctrl` + `K` | Find anything: games, mods, profiles, pages, settings |
| `N` | Add a mod (paste an address) |
| `F1` | Help |
| `F2` | Find anything |
| `F3` | Downloads |
| `F4` | Send from your phone |
| Arrow keys | In Steam Deck mode, move between buttons |
| `Enter` | Press the button in focus |
| `Esc` | Close a dialog or menu |

`F1` to `F4` are there so the Steam Deck's back buttons can be set to them.

## Controller

With a controller (Steam Deck, Xbox, PlayStation, 8BitDo…), in [Steam Deck mode](./steam-deck):

| Button | Does |
|---|---|
| D-pad or left stick | Moves between buttons |
| **A** | Presses (a text box opens Steam's keyboard) |
| **B** | Goes back, closes a dialog |
| **X** | Opens a thing's menu |
| **Y** | Plays the picked game's profile |
| **L1 / R1** | Previous and next page |
| **L2 / R2** | Scroll |
| **Menu** (☰) | Find anything |

Controller input is ignored while a game is starting or running, and when the window isn't in front.
