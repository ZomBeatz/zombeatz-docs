# Contact and feedback

## Getting help

1. Look in [When a game won't start](./troubleshooting) and [Questions](./faq).
2. **Settings › This computer › Save a report for getting help…** saves one file with what's useful for working out a problem (never your API key).
3. Ask on GitHub, with the report attached.

## Reporting a problem or asking for something

Open an issue on [GitHub](https://github.com/ZomBeatz/zoms-modzilla/issues): what you did, what happened, and what you expected. The report from step 2 helps a lot.

A problem with a mod itself (it crashes on Windows too, it needs an update) belongs on that mod's page on Nexus Mods.
