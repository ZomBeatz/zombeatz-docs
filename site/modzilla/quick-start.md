# Quick start

## 1. Install it

Download the file for your Linux (more detail in [Installing and updating](./installing)) from the [latest release](https://github.com/ZomBeatz/zoms-modzilla/releases/latest):

| Your Linux | File | How |
|---|---|---|
| Ubuntu, Linux Mint, Pop!_OS, Debian, Zorin | `.deb` | Open it with your software installer. |
| Fedora, Nobara, openSUSE | `.rpm` | Open it with your software installer. |
| Arch, CachyOS, Manjaro, SteamOS, anything else | `.AppImage` | Right-click › **Properties** › allow running it as a program, then open it. |

On a Steam Deck, use the AppImage in Desktop Mode, then see [Steam Deck](./steam-deck).

## 2. Follow "Getting started"

The app opens with a short checklist at the top:

1. **Connect your Nexus Mods account** ([more](./nexus-account)). Paste your personal API key from nexusmods.com › **Settings › API keys**. On a Deck, it's easiest in Desktop Mode, with copy and paste.
2. **Let the website's download buttons open Zom's Modzilla**, so **Mod manager download** sends files to the app.
3. **Find your games.** Steam games are found by themselves (Heroic and Lutris too); add others by hand.
4. **Get your first mod**, from **Browse** or the website.

![The Library: every mod you have, by game](/img/modzilla/library.png)

## 3. Make a profile and play

1. On **Profiles**, press **New profile…** and add mods (or let a collection make one).
2. Look at the problems the check finds: each one has a button to fix it.
3. Press **Play**. The profile's mods go into the game, the game's own files are kept aside, and the game starts.

**Take mods out** puts the game back as it came. **Play without mods** does that and starts the game.
