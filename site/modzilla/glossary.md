# Words used in Zom's Modzilla

| Word | Means |
|---|---|
| **Mod** | A change to a game someone made: new items, textures, fixes, whole quests. |
| **Library** | Every mod you've downloaded, each in its own folder. |
| **Profile** | A set of mods for one game, in order. One profile is in a game at a time. |
| **Put mods in / Take mods out** | Putting a profile's mods into the game folder (as links), and taking them out again so the game is as it came. Other managers call this *deploying*. |
| **Load order** | The order mods go in: a later mod wins when two have the same file. |
| **Plugin** | Bethesda games' `.esp`, `.esm` and `.esl` files, which load in an order of their own. |
| **Master** | A plugin another plugin needs. The game crashes if a master is missing. |
| **LOOT** | A community tool, and its list of rules, that sorts Bethesda plugins. |
| **Collection** | A curated list of mods on Nexus Mods, with its curator's choices. |
| **Revision** | A version of a collection. |
| **Add-on** | A named set of your own changes on top of a collection. |
| **Mod pack** | A small file listing a profile's mods, for sharing. |
| **Share code** | A mod pack as text (`ZM1-…`). |
| **Requirement** | A mod another mod needs, as listed on Nexus Mods. |
| **Installer (FOMOD)** | Steps a mod asks you through to choose its parts. |
| **Loader** | A program that loads mods into a game: SKSE, F4SE, SMAPI, BepInEx, RED4ext, UE4SS… |
| **Script extender** | A loader for Bethesda games (SKSE, F4SE, NVSE, FOSE, OBSE). |
| **Proton** | Valve's version of Wine, which runs Windows games on Linux. |
| **Prefix** | A game's own Windows folders under Proton (its `C:` drive, its settings, its saves). |
| **Protontricks** | A tool that installs Windows parts (Visual C++, .NET) into a game's prefix. |
| **Launch options** | Extra text in a Steam game's Properties that Steam adds when starting it, like `WINEDLLOVERRIDES="winmm=n,b" %command%`. |
| **API key** | Your personal key from Nexus Mods that lets the app use your account. |
| **nxm link** | The link the website's **Mod manager download** button opens; it carries a short-lived key for one file. |
| **Thunderstore** | Another mod site, for games like Valheim and Lethal Company. |
| **Restore point** | A note of a profile's mods each time it went in, to go back to. |
| **Save snapshot** | A copy of a game's saves, to put back later. |
