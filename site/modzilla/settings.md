# Settings

## Nexus Mods account

Your API key (see [Connecting Nexus Mods](./nexus-account)), **Remove key**, and keeping it in your desktop's keyring instead of a file.

## Nexus Mods links

Makes the website's **Mod manager download** buttons open Zom's Modzilla.

## This computer

What's set up and what's missing (tray, notifications, rar support, Protontricks…), with the command to install each one on your Linux. **Save a report for getting help…** saves one file to share when asking for help: versions, this computer, settings, games, profiles and downloads, never your API key.

## Logs

The app's own log, and the folder it's in.

## Steam Deck

**Add to Steam**, the controller and typing tips, and **Steam Deck mode**: bigger buttons and controller hints, **Automatic** (on a Deck or in Game Mode), **On** or **Off**. **Size** makes everything bigger or smaller (100% usual on a desktop, 120% in Steam Deck mode).

## Downloads

| Setting | Does |
|---|---|
| **How files download** | **Match my account**, **One at a time**, or **Several at once** ([Downloads](./downloads#one-at-a-time-or-several-at-once)) |
| **Downloads at once** | 1 to 8 |
| **Speed limit** | The most all downloads together may use |
| **Download hours** | Only start downloads between these hours |
| **While a game is running** | Carry on, hold new downloads, or pause them |
| **On battery** | New downloads wait below a charge |
| **Unpack on the charger** | On battery, leave unpacking for later |
| **Another speed limit for some hours** | A second limit for part of the day |
| **Try again by itself** | Retry a dropped connection up to 3 times |
| **Keep trying later** | And again after 5 minutes, 30 minutes and 2 hours |
| **Check downloads** | Compare each file with Nexus Mods' copy (one request each) |
| **Unpack downloads** | Unpack zip, 7z and rar files when they finish |
| **Keep archives after unpacking** | Keep the original file too |

## Storage

**Library folder**: where mods are kept. **A folder of its own for a game**: keep one game's mods elsewhere, like on its own drive.

## Copy mods instead of linking

Mods go into games as hard links: no extra space, but a tool that changes files in the game folder changes your library's copy too. Tick a game to always copy its mods instead (uses space on its drive).

## Activity

Which things the Activity page notes (games played, updates found, and so on).

## AI help

Optional: see [AI help](./ai-help).

## New versions

**Tell me when a newer Zom's Modzilla is out**: a daily check of GitHub's releases (not in the Flatpak, where Flathub updates it).

## Getting started

Show the *Getting started* checklist again.

## When the app closes

**Start with my computer**, **Open in the tray**, and **Unfinished downloads at start** (carry on, or keep paused).

## Appearance

**Theme** (**Match my computer**, **Light** or **Dark**) and **Adult mods** (show, blur or hide from Browse).

## Before uninstalling

Takes every game's mods out, so each game is back to how it came.

## Backup

**Save a backup…** and **Restore from a backup…**: see [Data and backups](./data-and-backups#app-backups).
