# Sending a board to a friend

Share a board with anyone who has Zomello, without a server or an account. They get their own copy.

1. On the board: **⋯ > Save as board file…**
2. Send the `.zomello` file however you like: email, a chat app, a USB stick, a cloud drive. On phones, **Share** sends it straight from Zomello.
3. Your friend opens it: double-click on a computer, or **Settings > Data > Import a board** on any device.

The board arrives with its buckets, cards, checklists, labels, notes and attached files.

## Good to know

- It's a copy: changes on their side don't come back to you. To work on the same board together, use a [Zomello Server](./family-server).
- Private calendar links on the board are left out.
- Opening the same file twice makes "Board name (2)".
