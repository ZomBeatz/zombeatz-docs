# Board files (.zomello)

A board file is one board, with its buckets, cards and attached files, in a single file you can send to anyone. Opening it adds the board as a new board; it doesn't need a server or an account.

## Save a board as a file

Board menu (**⋯**, or right-click the board) > **Save as board file…**

- **Windows and Linux:** it goes to your Downloads folder; click **Show** to see it.
- **Android:** Android's Save screen opens; pick a folder (Downloads, Drive…). Then **Share** sends it by email or chat.
- **iPhone and iPad:** the share sheet opens; save it to Files or send it.

## Open a board file

- **On a computer:** double-click the `.zomello` file, or drag it onto the Zomello window.
- **Anywhere:** **Settings > Data > Import a board**, then choose the file.

Opening the same file twice gives two boards ("Board name (2)"). Calendar feeds attached to the board aren't included, since they can be private links.

## Import from Trello or Planner

**Settings > Data > Import a board** also reads Trello exports (`.json`) and Microsoft Planner exports (`.xlsx` or `.csv`). It shows a preview of the buckets and cards before adding them.
