# Keyboard shortcuts and selecting cards

Zomello works fully with a mouse or touch; these are shortcuts for when your hands are on the keyboard. Press **?** in the app to see them anytime (they're also listed at the bottom of **Settings**).

## Anywhere

| Keys | Does |
|---|---|
| **Ctrl K** | Search everything |
| **N** or **Ctrl N** | Quick add a task |
| **Ctrl Z** | Undo |
| **Ctrl Shift Z** or **Ctrl Y** | Redo |
| **H** | Home |
| **M** | My Tasks |
| **[** | Fold or unfold the menu |
| **Ctrl +** / **Ctrl −** (or Ctrl and scroll) | Zoom in or out |
| **Ctrl 0** | Reset zoom |
| **?** | Help and shortcuts |
| **Esc** | Close a window or menu |

## On a board

| Keys | Does |
|---|---|
| **1** to **5** | Board, List, Calendar, Timeline, Charts |
| **/** | Filter cards |
| **B** | Customize the board |

## Pointing at a card

| Keys | Does |
|---|---|
| **Enter** or **E** | Open it |
| **C** | Complete (or un-complete) |
| **T** | Start or pause its timer |
| **F** | Start a focus countdown on it |
| **D** | Due today (press again: tomorrow) |
| **A** | Archive |
| **Shift D** | Duplicate |
| **Right-click** | Every card option |

## In an open card

| Keys | Does |
|---|---|
| **Alt ←** | Back to the card you came from |
| **Ctrl Enter** | Save the note you typed |
| **Ctrl B**, **Ctrl I**, **Ctrl E**, **Ctrl K** | Bold, italic, code, link (in the description and notes) |
| **Esc** | Close |

## Move cards without a mouse

1. Press **Tab** until a card (or a bucket) is highlighted.
2. Press **Shift Space** to pick it up.
3. Use the **arrow keys** to move it, **Space** to drop it, or **Esc** to cancel.

## Select several cards

**Ctrl click** cards to select them (Ctrl click again to unselect). A bar appears with:

- **Copy work order**: the selected cards as text (see [Copying and pasting cards](./copy-paste-cards))
- **Hand to AI…**: optional, see [AI tools](./ai-tools)
- **Complete** and **Archive**: all of them at once

**Esc** clears the selection.
