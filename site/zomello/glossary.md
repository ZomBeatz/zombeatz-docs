# Words used in Zomello

| Word | Means |
|---|---|
| **Board** | One project, area or list, made of buckets and cards |
| **Bucket** | A column on a board (called a list in Trello) |
| **Card** | One task |
| **Section** (or category) | A group of boards in the menu, like Work or Home |
| **Label** | A colored tag on cards, per board |
| **Progress** | Not started, In progress, Waiting, On hold, Completed |
| **Checklist** | Steps inside a card |
| **Sub-task** | A card linked from another card's checklist |
| **Linked task** | A card connected to another: related to, blocks or blocked by |
| **Custom field** | Your own piece of information on every card of a board |
| **Template** | A ready-made card you can add again and again |
| **Work order** | Cards copied as readable text, to paste elsewhere |
| **Board file** | A `.zomello` file with one whole board, to send to anyone |
| **Place** | Where boards live, shown as headings in the phone menu: this phone, your computer, a server |
| **Private board** | A board that never leaves the device it's on |
| **Pairing** | Connecting a phone or tablet to your computer, once, with a code |
| **Certificate** | A small file a phone installs once so it can trust your computer or server's secure (https) address |
| **Zomello Server** | Zomello for several people, with accounts, on an always-on computer |
| **Owner** | On a server: the person who controls a shared board |
| **Admin** | On a server: someone who manages people and every board |
| **Card aging** | Cards fading when nobody has touched them for a while |
| **WIP limit** | The most cards a bucket should hold at once |
| **Archive** | Where archived boards, buckets and cards wait until restored or deleted |
