# Custom fields

Custom fields add your own information to every card on a board: a client, a cost, a version number, "approved".

## Add fields

1. On the board, open **Customize** (or press **B**), then scroll to **Custom fields**. You can also click **Manage fields** inside any card.
2. Click **+**, name the field, and pick a type:

| Type | Holds | Example |
|---|---|---|
| **Text** | Any words | Client: "Acme Co." |
| **Number** | A number | Cost: 250 |
| **Dropdown** | One of your choices, each with a color | Size: Small / Big |
| **Checkbox** | Yes or no | Approved |
| **Date** | A date | Contract ends |
| **Link** | A web address, opens in your browser | Design file |

3. Tick **Show this field on cards in the board** for the ones you want to see without opening the card.
4. Use the arrows to reorder, and the trash to delete a field (its values go with it).

## Fill them in

Open a card: the **Fields** section shows every field of that board. Dropdown values show as colored pills on the card when the field is shown on cards.

## Good to know

- Fields belong to one board. **New board with this layout** copies them.
- Copied and pasted cards keep their field values when the new board has fields with the same names.
- The AI tools include fields, so an assistant can fill them in.
