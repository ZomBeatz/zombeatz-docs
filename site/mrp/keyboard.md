# Keyboard shortcuts

The same list is in **Settings > Shortcuts** and at the end of the in-app **Guide**. On a Mac, use <kbd>⌘</kbd> where it says <kbd>Ctrl</kbd>.

## Everywhere

| Keys | Does |
|---|---|
| <kbd>Ctrl</kbd> <kbd>K</kbd> | Find anything by name |
| <kbd>N</kbd> | New mission (or a new item on its own page) |
| <kbd>Ctrl</kbd> <kbd>Z</kbd> | Undo |
| <kbd>Ctrl</kbd> <kbd>Shift</kbd> <kbd>Z</kbd> | Redo |
| <kbd>[</kbd> | Fold the sidebar |
| <kbd>?</kbd> | The Guide |
| <kbd>Esc</kbd> | Close a form (it asks first if you've changed something) |

## Charts

| Keys | Does |
|---|---|
| <kbd>Ctrl</kbd> + scroll | Zoom in or out (or pinch) |
| <kbd>Shift</kbd> + scroll | Move through time (or drag) |
| <kbd>←</kbd> <kbd>→</kbd> | Move through time (Schedule) |
| <kbd>T</kbd> | Today on the Schedule |
| <kbd>+</kbd> <kbd>−</kbd> | Zoom the Schedule in or out |
| <kbd>Alt</kbd> while dragging a shift's end | Move just that shift, not the next person's (<kbd>Option</kbd> on a Mac) |
